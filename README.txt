AQUAFIND WATERPROOFING WEBSITE
================================

Files:
- index.html: Complete responsive website
- style.css: Design, colours and responsive mobile layout
- script.js: WhatsApp CTA links, enquiry form and mobile navigation
- assets/aquafind-logo.png: Logo with transparent background

HOW TO USE:
1. Extract the ZIP file.
2. Open the aquafind_website folder.
3. Double-click index.html to preview the website in a browser.
4. Upload the complete folder contents to your hosting/public_html folder.

WHATSAPP:
The WhatsApp number is set in script.js as 918005677079.
Change WHATSAPP_NUMBER if the business WhatsApp number is different.
All enquiry links open WhatsApp. The contact form fills in the message;
the visitor must press Send inside WhatsApp.
